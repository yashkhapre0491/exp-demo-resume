## 🚀 About the Project

**Legend YK Portfolio** is my personal developer portfolio website, designed with a modern dark theme, neon-blue and purple accents, and smooth CSS animations.

It showcases my technical interests, academic journey, projects, and ways to connect with me.

The website is built using **HTML5 and CSS3 only**, without JavaScript or external frameworks.

## ✨ Features

- 🎨 Modern dark-themed interface
- 💙 Neon-blue and purple visual effects
- 🖼️ Custom LEGEND YK profile artwork
- ✨ Floating animations and glowing effects
- 📱 Responsive layout for desktop, tablet, and mobile
- 👨‍💻 About Me and Technical Skills sections
- 🚀 Project showcase
- 🎓 Education timeline
- 📜 Certifications section
- 📬 Contact and social links
- ♿ Reduced-motion accessibility support
- ⚡ Lightweight frontend with no JavaScript dependency

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/yashkhapre0491/Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio
   ```

3. Ensure `index.html`, `style.css`, and `legend-yk.png` are in the same folder.

4. Open `index.html` in your browser.

No package installation or build process is required.
